# Techno Visual Archive

A visual catalogue of techno's graphic language — from Detroit to Berlin and beyond. ~6000 release covers sourced from Discogs, browsable by scene, label, and decade.

Static site. No backend. Images hotlinked from Discogs CDN. Hosted on GitHub Pages.

---

## Quick start

### 1. Get a Discogs token

1. Create account at [discogs.com](https://www.discogs.com)
2. Go to **Settings → Developers → Generate new token**
3. Copy the token

### 2. Collect the data

```bash
cd scripts

# Preview what will be collected
python collect.py --token YOUR_TOKEN --dry-run

# Run full collection (~90 labels, ~60-120 min depending on catalog sizes)
python collect.py --token YOUR_TOKEN

# If interrupted, resume where you left off
python collect.py --token YOUR_TOKEN --resume

# Test with a single label first
python collect.py --token YOUR_TOKEN --label "Tresor"
```

This creates `data/releases.json` with all release metadata and Discogs thumbnail URLs.

### 3. Test locally

```bash
# Any local server works. Examples:
python -m http.server 8000
# or
npx serve .
```

Open `http://localhost:8000`

### 4. Deploy to GitHub Pages

1. Create a new repo on GitHub
2. Push the project:
```bash
git init
git add .
git commit -m "Initial archive"
git remote add origin https://github.com/YOUR_USER/techno-visual-archive.git
git push -u origin main
```
3. Go to **Settings → Pages → Source: Deploy from a branch → main / root**
4. Site will be live at `https://YOUR_USER.github.io/techno-visual-archive/`

## Adding labels

Edit `scripts/labels.json`. Each label needs:
- `name`: Label name
- `discogs_id`: The numeric ID from the Discogs URL (e.g. discogs.com/label/**11** → Tresor)

Then re-run the collection script.

## Data model

Each release in `releases.json`:

| Field | Description |
|-------|-------------|
| `id` | Discogs release ID |
| `title` | Release title |
| `artist` | Artist name |
| `year` | Release year |
| `catno` | Catalog number |
| `thumb` | Discogs thumbnail URL (hotlinked) |
| `format` | Physical format (12", LP, CD, etc.) |
| `label` | Label name |
| `scene` | Geographic scene (Detroit, Berlin, etc.) |
| `discogs_url` | Link to Discogs release page |

## Notes

- Images are hotlinked from Discogs CDN — not downloaded or hosted
- The sample `data/releases.json` ships with 12 landmark releases for testing
- The full collection targets ~6000 releases across ~90 labels
- Discogs rate limit: 60 requests/min with auth token (~100 min for full collection)
- Collection is resumable — progress saved to `data/.progress.json`
