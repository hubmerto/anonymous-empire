Embed snippet (iframe)

Drop into any portfolio platform that accepts HTML embeds (Cargo, Framer, Webflow, Notion, Ghost):

<iframe
  src="https://anonymousempire.art/animations/deck/"
  width="100%"
  style="aspect-ratio: 1 / 1; border: 0; background: #000; display: block;"
  loading="lazy"
  allow="autoplay"
  title="Scene deck — looping animation"></iframe>

Swap the src for any URL above. Use aspect-ratio: 16 / 9 for landscape sections (hero, kinetic typography), 1 / 1 for the deck.
